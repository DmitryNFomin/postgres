## Primary results

Positive v10-minus-v9 overhead change means v10 had less overhead.

| Contrast | Estimate | 95% CI |
|---|---:|---:|
| v10 stats versus off | -0.024% | [-0.292%, +0.245%] |
| v10 trace versus off | -0.211% | [-0.612%, +0.192%] |
| v10-v9 stats-overhead change | +0.167% | [-0.193%, +0.528%] |
| v10-v9 trace-overhead change | +0.250% | [-0.276%, +0.778%] |

There were 32 sessions, 256 measured blocks, zero failed transactions, and a
maximum pgbench capacity fraction of 0.618. Placebo controls passed. The strict
statistical-suitability gate failed because bracket drift exceeded the +/-1%
limit, so these results are supportive rather than confirmatory.
